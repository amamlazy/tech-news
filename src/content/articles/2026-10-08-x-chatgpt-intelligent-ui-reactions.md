## 何が話題か

OpenAI が GPT-6 と「Intelligent UI」を ChatGPT の全ユーザーに広げると告知した投稿（@OpenAI）は、約1万3千件のいいねを集め、表示は160万回を超えた。機能の中身は同日の記事にまとめている。

## 開発者の投稿

OpenAI の Michelle Pokrass 氏（@michpokrass）は、「Intelligent UI はモデルの知能への賭けだ」と投稿した。GPT-6 に、役に立つ視覚的・対話的な部品で画面を埋めさせる、ChatGPT にとってかなり大きな変更だという。そのために、トークン効率がよく、すぐにストリーミング表示でき、自社のデザイン言語に合い、どんな話題にも対応できる表現力を持つ画面を作れる道具を整える必要があった、と書いている。

同じく開発に関わった Isa Fulford 氏（@isafulf）は、Intelligent UI と「考えながら答え始める」機能を含む今回の公開は、チームの数カ月の成果だと投稿している。Greg Brockman 氏（@gdb）も機能を紹介した。

## 反応

ユーザー側では、夕食の計画を頼むと人数を変えれば買い物リストが更新される、といった使い方を紹介する投稿が広がっている。Plus ユーザーからは、最新のモデルや機能が通常のチャット以外に先に来ていたので、ようやく待っていた更新が来たという趣旨の投稿も出ている。

## 現場で見るところ

回答の形をモデル自身が選ぶ設計は、AI を組み込むアプリ側の UI づくりにも影響しそうだ。部品ライブラリとストリーミング前提の描画という作り方は、自社プロダクトで生成 UI を試すときの参考になる。
