MAI（マイ）は、マイクロソフトのAI部門「Microsoft AI」が自社で開発しているAIモデルのシリーズです。今回の「MAI Code 2」は、その中でもプログラムを書くことに特化したモデルです。

## 何が発表されたか

Publickeyによると、マイクロソフトは日本時間11月18日未明に始まった年次イベント「Microsoft Ignite 2026」で、企業の日常的なコーディング作業向けの2つのモデルを発表しました。どちらも「競合と同じくらいの性能を、より安く」がセールスポイントです。

## MAI Code 2：本番向けの本格派

MAI Code 2は、本番環境で動かすコードの生成、難しいデバッグ（不具合の原因探し）、リポジトリ全体を読んだうえでの推論、ダッシュボードなどの画面づくりが得意なモデルとされています。

マイクロソフトは、GitHub Copilotでよく見られる企業向けコーディング作業を対象にした4つのベンチマークの平均で、MAI Code 2は次の結果だったとしています。

- GPT 6.1 Solの98％の性能を、40％のコストで
- Claude Opus 5.5の96％の性能を、わずか5％のコストで

## MAI Code 2 Flash：安さ重視の日常用

MAI Code 2 Flashは、コードの解説、一部分だけの編集、決まりきった修正など、毎日大量に発生する作業向けです。3つのベンチマークで、GPT-6 LunaやClaude Haiku 5.5と同等の性能を、GPT-6 Lunaの65％、Claude Haiku 5.5の20％程度のコストで出したとしています。

## 見るところ

数字はいずれもマイクロソフトの自社測定です。GitHubの公式Xアカウントは、両モデルがGitHub Copilotで一般提供（GA）になったと投稿しています。普段Copilotを使っている人は、モデルの選択肢として試しやすくなりました。マイクロソフトはIgniteで、画像編集向けの「MAI Image 2.7」などを含む計7つのMAIモデルを発表しています。
