## 何が話題か

X 上で Yuchen Jin 氏（@Yuchenj_UW）が、「しばらく Claude Code も Codex CLI も触っていない。ターミナルの時代は終わったと思う。コーディングエージェントにとって間違ったインターフェースだ」と投稿した。タブは一時的だがコンテキストは持続するもので、30個のタブを管理するのは純粋な認知負荷だ、とも書いている。

同氏は続く投稿で、15年以上ターミナル派で Vim のショートカットも覚えていたが、ターミナルは人が直接ファイルやコマンド、プロセスを操作することを前提にしており、エージェントがそれを変えた、と説明している。

## 反応

X 上のニュース要約では、人が意図を伝えてエージェントが細部を処理するデスクトップアプリ型の環境へ移る流れとして取り上げられている。一方で、ニッチな作業にはまだターミナルが向いているという声もあると整理されている。

## 現場で見るところ

どの UI が良いかは作業によって違い、投稿は個人の使い方の話でもある。複数のエージェントを並行して走らせるなら、セッションとコンテキストの管理をどこで行うかを、ツール選びの基準として意識しておくとよさそうだ。
