これは、Qiitaに投稿された実践レポート（筆者：suwa_nobu氏）の紹介です。題材のClaude Fable 5.2は、Anthropicが11月10日（日本時間）に公開した上位のAIモデルで、Claude Code（ターミナルで動くAIプログラミング支援ツール）でも同日から選べるようになりました（前日の記事参照）。

## 何を確かめたのか

Anthropicは、Fable 5.2について「料金が下がった（100万トークンあたり入力8ドル・出力40ドル）」「出力がFable 5.1より最大30％速い」「難しい仕事を5.1より少ないトークンでこなす」と発表しています。一方、公式はまずOpus 5.5（料金はFable 5.2のちょうど半分）から始めるよう勧めています。筆者は、普段のClaude Codeの仕事で本当に速く安くなるのかを測りました。

## 試し方

- 測定日は11月10日。Claude Code 2.1.321をWindows 10で、`claude -p`（対話なしの実行）で動かした
- effortは3モデルともClaude Codeの既定のMedium。ファイルの読み書きとnodeコマンドだけ許可し、Web検索は止めた
- 課題は4つ（時間文字列の変換、カート合計のバグ修正、todoへの機能追加、引っかけの多い電卓）。AIに見せるテストと見せないテストを用意し、見せたテストだけ通す「ずる」も見抜けるようにした
- 3モデル×4課題×3回＝36回

頼んだ文の例は「src/calc.js の evaluate を、ファイルの先頭のコメントの仕様どおりに実装して。node --test で test/ のテストが全部通ることを確かめて。」です。

## 結果

- **速さ**：1秒あたりの出力はFable 5.1の1.32倍で、かかった時間は約2割短縮。発表どおりでした
- **トークン**：出力トークンの中央値はFable 5.2が2,418、5.1が2,175で、むしろ約1割多め。「少ないトークンで」は見えませんでした（筆者は、易しめの課題だったためかもしれないとしています）
- **費用**：12回の合計はFable 5.2が3.44ドル、5.1が4.87ドル、Opus 5.5が2.10ドル。5.1より29％安い一方、Opus 5.5の1.64倍でした
- **正しさ**：4課題とも3モデルすべてがテストを通し、差は出ませんでした

## 注意点

筆者が驚いたのは費用の内訳で、Fable 5.2では1回の費用の約6割が、モデルの出力ではなく、Claude Codeが会話の頭をキャッシュ（再利用のための一時保存）に書き込む分だったといいます。費用はMaxプランでの推定値で、実際に請求される額ではありません。また、発表がうたう「難しい仕事」は試していない点も明記されています。
