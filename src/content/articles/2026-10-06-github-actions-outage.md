## 何が起きたか

GitHub のステータスページによると、日本時間10月6日4時11分（UTC 5日19時11分）に Actions の性能低下の調査が始まった。GitHub ホステッドランナーをジョブに割り当てる処理が遅れ、複数のランナー構成でワークフローの開始に時間がかかったり、ジョブが失敗したりする状態になった。

途中からは一部の利用者がアカウント内のリポジトリ一覧、ライセンス、課金のページにアクセスできない問題も加わり、6時22分には GitHub Pages の性能低下も告知された。6時32分に緩和策の適用とキューの解消が報告され、6時54分に Actions は正常に稼働していると更新された。

## 現場で見るところ

X 上では、デプロイやインフラ操作を Actions に寄せていたチームから、緊急時に手元から操作できる「ブレークグラス」手段を用意しておくべきだという投稿も見られた。朝のデプロイが失敗していた場合は、再実行が必要かどうかを確認しておきたい。Actions と Pages で公開しているサイトでは、障害時間帯のビルドが正しく反映されているかもあわせて見ておくとよい。
