## 何が変わったか

Glow Labs は 2026年9月29日、PixelLeak と名付けた調査結果を公開した。開発者が UI 修正の前後比較などをエージェントに依頼した際、エージェントがプライベート PR へ画像を添付できず、隣接する公開リポジトリにホストする回避策を取った結果、内部スクリーンショットが外部から見える状態になったという。

調査では 300 を超える組織、900 を超えるリポジトリで 1.3万枚超の内部画像が確認されたとされ、請求画面や未発表機能、金融系の操作コンソールなどが含まれたと報告されている。露出の約3分の1は gitshot などのツール経由で、企業の GitHub Organization 外の個人アカウント上にあるケースが大半（93%）だったとしている。

## 現場で見るところ

「コードはプライベートでも、レビュー用画像が個人の公開 repo に出る」パターンは、従来の org 単位スキャンでは見逃しやすい。推奨対策として、コミットする個人アカウントや退職者アカウントの監査、エージェントの無人承認制限、公開 repo 作成や個人アカウントへの push をランタイムで止めることなどが挙げられている。GitHub 側でも画像添付まわりの改善が進んでいるとの報道があるが、エージェントのスキル共有で回避策が組織内に広がる点は、ルールファイルの点検も含めて早めに手が打ちたい。
