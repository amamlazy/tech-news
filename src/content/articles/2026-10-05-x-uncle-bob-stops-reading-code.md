## 何が話題か

X 上で『Clean Code』の著者 Robert C. Martin 氏（@unclebobmartin、通称 Uncle Bob）が、「Clean Code の著者がもうコードを読まないと聞いて驚く人がいるが、意外なことではない」と投稿した。なぜ Clean Code を書いたのか、コードをきれいに保つ目的は何か、それは本当の仕事である「考えること」の邪魔にならないようにするためだ、という趣旨だ。投稿の表示回数は100万回を超えている。

この投稿をきっかけに、AI が生成したコードをどこまで人が読むべきかという議論が広がった。「AI のコードを一行ずつレビューするのはもう現実的ではないので、コードレビューをサービスとして提供するツールが必要だ」という投稿がある一方、「AI がコーディングに強くなるほど、コードを本当に理解することが重要になる」という反対意見も投稿されている。

## 現場で見るところ

X 上のニュース要約では、テストやメトリクス、上位レベルの監視で行単位のレビューを置き換えられるという意見と、デバッグや保守のためには構造の理解が欠かせないという意見に分かれていると整理されている。チームとしては、どの変更を人が読み、どこをテストや自動チェックに任せるかの線引きを明文化しておくことが議論の出発点になりそうだ。
