## 何が変わったか

GitHub は10月8日、プルリクエスト制限の設定でドラフト PR も件数に含めるオプションを追加した。メンテナーが低品質なコントリビューションに困っている、という背景がある。

以前はドラフト PR はユーザー上限に入らなかった。制限をかけても下書きだけを無数に開け、通知や CI 実行を増やせる抜け穴になっていた。ドラフトを数えることで、その抜け道を狭め、リポジトリの雑多さを減らす狙いだと Changelog は説明している。

## 運用上の注意

設定を有効にすると、下書き中の作業者も上限に引っかかる可能性がある。正当な WIP が多いチームでは、上限値の見直しとあわせて導入した方が安全だ。フィードバックは Community の議論スレッドで受け付けている。
