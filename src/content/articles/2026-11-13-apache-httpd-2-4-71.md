Apache HTTP Server（アパッチ、httpd）は、The Apache Software Foundation（ASF）が開発しているオープンソースのWebサーバーソフトで、世界中のWebサイトで長く使われてきました。このサイトでは11月9日に2.4.70の公開を伝えましたが、今回はその次の版です。

## 何が修正されたか

窓の杜によると、2.4.71では次の3件の脆弱性（セキュリティ上の欠陥）が修正されました。

- **CVE-2026-119618**（Critical）：mod_http2のヒープ破損とリモートコード実行
- **CVE-2026-106023**（Important）：mod_mdのNULLポインタ参照で子プロセスが落ちる
- **CVE-2026-109163**（Low）：mod_vhost_aliasでスタック上の1バイトを書き越える

特に注意したいのは、4段階で最も深刻な「Critical」とされたCVE-2026-119618です。HTTP/2（Webの通信方式の一つ）を処理する「mod_http2」の `assign_headers()` 関数に、共有するデータの扱いが正しく同期されない競合状態の欠陥があり、外部からコードを実行されるおそれがあります。

## 影響を受けるバージョン

- Apache HTTP Server v2.4.55〜v2.4.70
- GitHubで公開されているHTTP/2モジュール「mod_h2」のv2.0.8〜v2.0.42

このほか、mod_deflateやmod_dav、mod_remoteipなどの不具合修正と、mod_mdの機能改善も含まれています。

## 現場で見るところ

HTTP/2を有効にしているサーバーは、早めに2.4.71へ更新するのが安全です。OSのパッケージで入れている場合は、ディストリビューションから修正版が届いているかを確認しましょう。すぐに更新できない場合、HTTP/2を一時的に無効にすることも選択肢になりますが、その場合は表示速度などへの影響も確認が必要です。
