Claude API（クロード エーピーアイ）は、AnthropicのAI「Claude」を自分のプログラムから呼び出すための仕組みです。この記事は、moritalous氏がQiitaに書いた実践レポートで、最近のClaude APIに加わった新しい使い方を、実際にコードを動かして確かめています。

## 準備

氏は、Pythonのプロジェクトを作ってAnthropicの公式SDKを入れ、APIキーを使わずにログインするために `ant` コマンドを使っています。

```bash
uv init app --python 3.13 --no-package
cd app
uv add anthropic
mise use github:anthropics/anthropic-cli
ant auth login
```

試したモデルは `claude-haiku-5-5` です。

## 会話の途中でシステムプロンプトを足す

システムプロンプトとは、AIに「どういう立場で答えるか」を最初に伝える指示のことです。今のClaude APIでは、これを会話の途中に追加できます。

例として、1回目は「あなたは親切なアシスタントです」で朝ごはんを聞き、2回目で「ここからは英語で答えてね」というシステムプロンプトを足すと、昼ごはんの答えが英語になりました。追加するシステムプロンプトは、ユーザーの発言の後ろに置く必要があります。

ポイントは、**プロンプトキャッシュを保ったまま変えられる**ことです。プロンプトキャッシュとは、前と同じ部分の計算結果を使い回して、料金や待ち時間を減らす仕組みです。最初の指示を書き換えるとキャッシュが使えなくなりますが、後ろに足すならそのまま使えます。

## ツールや思考レベルも途中で変えられる

同じ仕組みで、次のこともできます（投稿時点ではいずれもベータ機能）。

- **ツールの追加・削除**：AIが使える機能（ツール）を途中で足せる。`inline-tools-2026-09-15` の指定が必要。外すときは `tool_removal` を使う。天気だけ調べられる状態から、2回目で時刻を調べるツールを足すと、両方使って答えた
- **思考レベル（effort）の変更**：AIがどれだけ考えるかを途中で変えられる。`mid-conversation-output-config-2026-07-01` の指定が必要。高→低→高と変えると、考えに使ったトークン数は465→0→169になった
- **1回だけ有効な指示**：`clear_at` に `next_user_message` を指定すると、その指示は次の発言までだけ有効になる。`mid-conversation-system-clear-at-2026-08-21` の指定が必要

最後の例では、「毎回ランダムな言語で1文あいさつして」という指示のもと、5回目だけ「絶対にフランス語で」と差し込むと、5回目はフランス語、6回目はまたランダムに戻りました。

## 注意したいところ

ベータ機能ごとに指定する名前が微妙に違うので、取り違えに注意が必要だと氏は書いています。また、AIの返事に思考のブロックが入ることがあるため、文字の部分だけを取り出すコードにしておく必要があります。

氏は記事を「APIの進化、それはプロンプトキャッシュとの戦い」とまとめています。長い会話を続けるAIエージェントを作る人にとって、料金と速さを保ったまま振る舞いを変える方法として役立ちそうです。
