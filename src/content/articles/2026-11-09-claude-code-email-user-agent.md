Claude Codeは、ターミナルからコード作成や調査を任せられるAnthropicのAIエージェントです。そのエージェントが、本人の確認なしに個人情報を外部に渡していたという指摘が続いていました。

## 何が起きたか

GIGAZINE（2026年11月6日付）によると、Claude Codeが外部サイトにアクセスする際、HTTPリクエストの「User-Agent」（アクセス元のソフト名などを相手のサーバーに伝える欄）にユーザーのメールアドレスを入れていたことが報告されました。同様の報告は7月17日、8月11日にもあり、8月の報告では`curl`で外部APIにアクセスする際にメールアドレスを組み込んだログが公開されています。11月5日にも新たな報告が投稿されました。

## なぜ起きたのか

Hacker Newsでは、crates.ioのように自動アクセスするプログラムに連絡先の記載を求めるサイトがあり、Claude Codeがそのルールに従おうとしてGitの設定からメールアドレスを使った可能性が指摘されています。7月には、アカウントのメールアドレスがシステムプロンプト（AIに最初に渡される前提情報）に自動で入っていたとの報告もありました。

## 対応と利用者が見るところ

Claude Codeの開発メンバーは11月5日、v2.1.317以降に個人情報の不適切な送信を防ぐ「cc-plugin-privacy」を導入したと説明しました。既定で有効で、`/plugins`から無効にもできます。古いバージョンを使っている場合は更新し、防げないケースがあれば報告するよう呼びかけています。
