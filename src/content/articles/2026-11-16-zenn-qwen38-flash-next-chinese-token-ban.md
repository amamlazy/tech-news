Qwen（クウェン）は、中国のAlibabaが開発しているAIモデルのシリーズで、重みが公開されているので自分のPCでも動かせます。ただ、日本語で質問しても、答えに中国語の漢字や単語が混ざることがあります。この記事は、CAPH TECHのrizumita氏による実践レポートで、その混入をモデルの一部を書き換えて止めた記録です。

## 何が困っていたのか

氏は、メモリ128GBのMacで、Qwen3.8-Flash-Nextの4ビット版を「mlx-serve」というツールで動かしています。医療の質問を日本語ですると、次のように中国語が混ざったといいます。

- 「誤って」が簡体字の「误って」になる
- 前の行では「給水管」と書けているのに、次の行で「给水管」になる
- 「这样的」「啤酒」のような中国語の単語がそのまま出る

医療の質問60問で調べると、選択問題では40問中3問でしたが、自由記述では20問中13問で混ざりました。長い説明文ほど混ざりやすいようです。

## やったこと

AIは次の語を選ぶとき、最後の「出力層」で語ごとの点数を計算し、点数の高い語を選びます。出力層は、語（トークン）の数だけ行がある表のようなものです。

Qwenの出力層は248,320行ありますが、実際の語は248,077個しかなく、残りの243行はどの語にも使われていません。そこで、中国語に当たる25,451語の行を、この「使われていない行」の写しに置き換えました。こうすると、中国語の語が選ばれにくくなります。禁止する語は、JIS X 0213（日本語の漢字の規格）にない漢字を含むトークンと、中国語版Wikipediaにばかり出てくる語から選びました。

書き換えは、自社で公開しているツール「Kestrom」で、次のように1つのコマンドで行えます。

```bash
git clone https://github.com/CAPHTECH/kestrom && cd kestrom
pip install "./verify[mlx]" "./edit[mlx]"
kestrom rows ban ~/models/mlx/Qwen3.8-Flash-Next "" examples/zh-ban/list.txt id:248077 ~/models/mlx/Qwen3.8-Flash-Next-nozh
```

コピーされるのは出力層の入ったファイル（約650MB）だけで、残りの100GB近いファイルは元へのリンクになります。

## 「ほかは変わっていない」を確かめる

氏が重視しているのは、書き換えたあとに「ほかに何が変わったか」を、作った人の説明ではなくデータで確かめられることです。

- 元のモデルと書き換えたモデルのファイルをバイト単位で比べ、変わったのは禁止した行だけだった
- 同じ条件で60問を生成し直すと、書き換えたモデルの答えは元と一字も違わなかった
- 中国語の混入は、同じ条件で27%から0%になった

ただし、mlx-serveに同じ質問を読み込み直さずに2回目に送ると、元のモデル同士でも答えが変わることがあったと注意しています。

## 限界

氏は、限界もはっきり書いています。

- 禁止は語単位なので、以前のQwen3.5-9Bでは「両性具有」が「両性具」になるなど、禁止した語でしか書けない日本語が書けなくなる例があった
- 試したのはMLX版だけで、LM Studioやllama.cppで使うGGUF版では未確認
- 60問は少なく、問いも医療だけ

ローカルのAIを日本語の業務で使いたい人にとって、モデルを作り直さずに困りごとを減らす方法として参考になりそうです。
