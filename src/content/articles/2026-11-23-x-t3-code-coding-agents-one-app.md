AIコーディングエージェントは、Claude Code（Anthropic）やCodex（OpenAI）のように、指示を受けてコードを書いたり直したりするAIツールです。T3 Code（ティースリー・コード）は、こうした複数のエージェントを1つのアプリから扱うためのツールで、人気開発者Theo（テオ）氏のチームが手がけています。

## 何が投稿されたか

Riley Brown氏は日本時間11月23日早朝、「ようやくt3codeを覚える時間を取った。2カ月前に試したときは開発者向けすぎたが、ここまで進んでいるとは思わなかった」と投稿しました。取得時点でいいね427件、リポスト9件、表示25,161回、ブックマーク205件です。投稿で紹介されている使い方は次のとおりです。

- ClaudeのArtifacts（会話の中で作る文書やアプリ）がT3 Codeの中でもよく動き、T3 Codeのブラウザーで開ける
- iOSアプリとの接続はQRコードを読む必要すらなく、スマホからT3 Codeのブラウザーを操作できた
- 動画の理解はGemini、動画を編集するコードを書くのはClaudeが得意なので、ClaudeにGeminiのサブエージェントを立ち上げさせ、20本以上の動画を分析させてから編集させられる
- 1つのプロンプトから、複数のモデルに同じ動画の編集を試させて比べられる

Dan McAteer氏も「金曜にT3 Codeを入れたけど、実際すごくいい」と投稿しています（いいね177件）。

## どんなツールか

Xの話題まとめによると、T3 Codeはオープンソースで、Claude Code、Codex、Grok Buildなどのエージェントを、デスクトップアプリ、Webの画面、iOS/Androidアプリから1か所で操作できます。作業ごとに独立したGitのワークツリー（同じリポジトリの別の作業場所）を使える点や、ワンクリックでプルリクエストを作れる点も挙げられています。

kr0der氏は、ほかのAIコーディングアプリの不満として「小さな色付きの丸で状態を示すので分かりにくい」「複数の作業を同時に管理しにくい」を挙げ、T3 Codeは「✅ Done」「? Input」と文字で示し、自分の対応が必要なものだけが見えるサイドバーになっていると評価しています。
