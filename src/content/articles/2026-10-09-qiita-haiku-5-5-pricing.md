## どんな実践報告か

これは kai_kou 氏による Claude Haiku 5.5 の実測レポート（2026年10月7日投稿）だ。公式の「平均約75%安い」といった主張をそのまま信じず、Claude Code 2.1.293 の `claude -p` から Haiku 5.5 / 4.5 を呼び出し、料金境界・effort・速度を測っている。

対象読者は、サブエージェントなどで Haiku 4.5 を使っており 5.5 へ切り替える開発者だ。ツールは無効化し、システムプロンプトも短い一文に差し替えて、Claude Code 本体の大きな文脈が混ざらないよう工夫している。

## 100K境界の測り方

日本語ドキュメントをつなげた約13.9万トークンの資料を `--effort low` で送ると、キャッシュ書き込み1回目の `total_cost_usd` は約0.139ドル、読み込み2回目は約0.0076ドルだった。単価から逆算すると、どちらも「100K超」帯と一致する。超えた分だけでなくプロンプト全体と出力が高い単価になり、キャッシュから読んだトークンも長さに含まれる、というのが著者の読みだ。約3.8万トークンでは100K以下の単価と一致した。

## effortと速度

同じ資料で「『投稿上限』という語はあるか」と聞くと、effort `low` は思考トークン0で2回とも「はい」（誤り）、`medium` / `high` は約440トークン考えて「いいえ」と正答した。一方、分類のような短い処理では `high` でも思考0になり、Haiku 5.5 は API 時間460ms・約0.00028ドル、Haiku 4.5 は約4.3秒・0.0020ドルだった。切り替え時はモデル ID 差し替えだけでなく、自分の入力で effort ごとの正誤を一度測るよう勧めている。
