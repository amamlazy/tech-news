GitHub Copilot（コパイロット）は、GitHubが提供するAIのプログラミング支援サービスです。今回の拡張機能は、それをWebブラウザーの中で使えるようにするもので、ブラウザーを操作する「エージェント」として働きます。

## 何が投稿されたか

GitHubの公式アカウントは日本時間11月18日午前4時29分ごろ、「#MSIgniteからの新発表：Google Chrome向けGitHub Copilot拡張機能をダウンロードしよう。すでにサインインしているブラウザーで、フォームの入力、Webページからの情報の取り出し、作っているWebアプリのテストやデバッグをCopilotに頼める。Google ChromeとMicrosoft Edgeで試して」と動画付きで投稿しました。取得時点でいいね102件、リポスト13件、表示1万3834回です。

## 何がうれしいか

すでにログインしているブラウザーで動くため、作業のたびに別の環境でログインし直す手間が減ります。開発者にとっては、自分のWebアプリを実際にブラウザーで動かしながら、AIに画面を操作させて不具合を探してもらう使い方ができそうです。一方で、ログイン済みのサービスをAIが操作できるということでもあるので、どのサイトで何を許可するかには注意が必要です。

## そのほかのIgnite関連の発表

GitHubは同じ日、デスクトップの「GitHub Copilotアプリ」がAzure DevOpsと連携し、Azure DevOpsのリポジトリをクローンしてプルリクエストを最後まで進められるようになったとも投稿しています（いいね107件）。レビューコメントの「Fix」を押すとエージェントが対応する機能もあるとしています。また、複数のモデルを自動で使い分ける「Copilot Fusion」の最上位設定「Fusion Max」が、Terminal-Bench 4.1で71.2％の解決率を出したとも発表しました。
