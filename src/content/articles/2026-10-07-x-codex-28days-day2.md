## 何が話題か

OpenAI で Codex を担当する Tibo 氏（@thsottiaux）が、28日間続ける発表企画の2日目の内容をまとめて投稿した。1,600件以上のいいねを集めている。

投稿に並んだ項目は次のとおり。

- 「Approve for me」（自動レビュー）を利用枠の消費なしで使えるようにした。使い方によっては、これまでプランの利用枠の2〜10%を占めていたという
- 開発者向けの API を簡素にした
- 会議メモを統合した
- Decisions API を公開した

Tibo 氏は別の投稿で「Decisions API が公開された。自分たちでもこれを使う」とも書いている。Decisions API の中身は同日の記事にまとめた。

## 1日目との流れ

PC Watch によると、企画の1日目には GPT-6 Astra と GPT-6.1 Sol の生成速度が、サブスクリプションと「Sign in with ChatGPT」のパートナー向けに約50%（毎秒30トークンから50トークン）上がった。企画の開始そのものは10月6日の記事で紹介している。

## 現場で見るところ

「Approve for me」は、エージェントの操作の承認を AI のレビューに任せ、毎回確認を求められる手間を減らす機能だ。それが利用枠を食わなくなったことで、長い自律作業を回すときの残量の心配が少し減る。28日間の発表が続くので、日々の変更が自分のワークフローに効くかは追いかけておきたい。
