GitHub Copilot（コピロット）は、GitHubが提供する「コードを書くのを手伝うAI」です。そのCopilotに、プロジェクトについての“覚え書き”をAI自身が定期的に見直して、最新の状態に保つ新機能「Dreaming（ドリーミング＝夢を見る）」が加わりました。

## 何が発表されたのか

Publickeyによると、GitHubは10月28日〜29日に米サンフランシスコで開催した年次イベント「GitHub Universe 2026」で、Copilotの新機能「Dreaming」をパブリックプレビュー（正式版の前に誰でも試せる公開テスト版）として発表しました。

Copilotには「Copilot Memory」という、プロジェクトごとの情報を覚えておく仕組みがあります。たとえば次のような情報です。

- コーディングのルール（書き方の決まりごと）
- アーキテクチャ（システム全体の構成）
- プロジェクトで使うコマンド

Dreamingは、こうしたガイダンス（AI向けの手引き）を、人が作業していない間もバックグラウンドで整理し直したり、更新したりする機能です。人が眠っている間に記憶を整理する「夢」になぞらえた名前だと考えると分かりやすいでしょう。

## どうやって学ぶのか

Dreamingは、開発者とCopilotのチャットでのやり取りや、プルリクエスト（PR：コードの変更を取り込んでもらうための依頼）のレビュー内容から学習します。たとえばレビューで「この書き方はやめてほしい」と何度も指摘されたら、その内容を手引きに反映するといったイメージです。

イベントのデモでは、JavaのアプリケーションをSvelte（スベルト：Webの画面を作るための仕組み）とJavaScriptで書き直す作業が紹介されました。コードの書き換えに合わせて、Dreamingが指示ファイル（AIに守らせたいルールを書いたファイル）も書き直し、その変更をPRとして送ってきたといいます。

## 読みどころ

AIにコードを書かせる開発では、「AI向けの説明書」を人が手で更新し続ける手間が課題になっていました。Dreamingは、その説明書の更新までAIに任せ、人はPRを確認して取り込むかどうかを決めるだけ、という形を目指しています。勝手に書き換えるのではなくPRで提案する点が、人が最終判断を持てる設計になっています。
