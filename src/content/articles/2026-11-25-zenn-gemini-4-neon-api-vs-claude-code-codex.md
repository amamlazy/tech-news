この記事は、株式会社カンリーのCAIO（最高AI責任者）萩野氏がZennで公開した検証レポートの紹介です。Gemini 4 Neon（ジェミニ4ネオン）は、Googleが2026年11月18日に公開した最新のAIモデルで、一度に約100万トークン（トークンはAIが文章を数える単位）まで読み込めるのが特徴です。

## 何を比べたか

萩野氏は、Gemini 4 Neon（API経由）、Claude Opus 5.5（Claude Code経由）、GPT-6.2 Sol（Codex CLI経由）を、同じ8つの課題で比べました。数学・論理、グラフの読み取り、17万トークンの文書検索、8万トークンのグラフ探索、39万・65万トークンの超長文検索、HTMLのゲーム作成、日本語の文章作成などです。各課題1回ずつの実測で、プロンプト全文や正解データの作り方は付録に載せています。

Claude Codeは `claude -p --model claude-opus-5-5 --effort high --output-format json --tools ""` のようにヘッドレス（対話画面を開かない）で、Codex CLIは `codex exec ... -c 'model_reasoning_effort="high"' -s read-only --json` で実行し、推論の深さをそろえています。

## 結果

- **正答率**：正解が決まる課題は、実行できたものはすべて満点で差はつきませんでした。
- **超長文**：39万・65万トークンでは、Neon（23.2秒／29.8秒、1.19ドル／1.99ドル）とOpus（26.6秒／40.1秒）がどちらも全問正解。GPT-6.2 Solは、Codex CLIが1,048,576文字を超える入力を拒否したため渡せませんでした。
- **速さ**：HTMLのゲーム生成はNeonが137秒で最速、数学はGPT-6.2 Solが81秒で最速でした。
- **費用**：Neonの成功したリクエストの合計は5.300ドル。超長文では費用のほぼすべてが入力分でした。

## 実務で役立つ気づき

萩野氏は、モデルごとに「思考トークン（答える前に考える量）」の使い方が違うと指摘します。Neonは既定の思考レベルがHIGHのため、短い課題でも4〜5千トークン考えて36〜43秒かかりました（他の2つは7〜18秒）。短い問い合わせが多い用途なら、LOWやMEDIUMを試す価値があるとしています（今回は未検証）。

また、トークナイザー（文章をトークンに区切る方式）の違いで費用の見積もりが変わる点にも注意を促しています。同じ小説1冊がNeonでは約17.1万トークン、Claudeでは約24.7万トークンと数えられました。日本語の文章の相互採点では3者ともGPTを1位にしましたが、採点役が自分の文章も採点しているため偏りの可能性があると、限界も明記しています。
