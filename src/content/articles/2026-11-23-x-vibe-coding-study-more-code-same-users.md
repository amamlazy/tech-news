バイブコーディング（vibe coding）は、細かいコードを自分で書かずに、AIに「こういうものを作って」と話しかけながらソフトウェアを作るスタイルのことです。AIで作るのが簡単になった結果、本当に役立つソフトが増えたのかを調べた研究が話題になりました。

## 何が投稿されたか

thesupermannx氏は日本時間11月21日夜、「MITがバイブコーディングについて最も居心地の悪い論文を出した」として、研究の内容を紹介しました。取得時点でいいね2,543件、リポスト418件、表示163,089回、ブックマーク1,520件です。投稿によると、研究はコーディングエージェントの登場後にApp Store、Google Play、Chromeウェブストアなどに出た新しいアプリを追跡したもので、次のような結果だったといいます。

- 自律型のエージェントを使い始めた開発者は、コードを25.5倍書き、コミットは240%増、触るリポジトリは80%増。しかし実際のリリースは30%増にとどまった
- Claude Codeのようなツールを導入した開発者は、書く行数が7倍、削除する行数が12.2倍に。30日以内に放棄されるリポジトリの割合は60%から69%に上がった
- 各ストアに出る新しいアプリは2025年初めから約2倍になったが、利用者の関与は変わらなかった

投稿者は、自分も先月Claude Codeで3つの「プロジェクト」を出したが、たぶん誰も使っていないと振り返り、「コードを書くことは本当のボトルネックではなかった。まとまったものを出荷し、きちんとレビューし、誰かが欲しいものを作ることがボトルネックだった」と述べています。

## 反応

Xの話題まとめでは、この研究は全米経済研究所（NBER）の論文として紹介されており、投稿の「MIT」という表現とは食い違いがあります。論文の正確な出典や数値は、元の論文で確かめるのが確実です。

返信では「Claudeが100時間節約してくれても、それが自然にユーザーに変わるわけではない。その半分を、アプリを人に届けることに使おう」（andrebarbera_氏）といった声が上がりました。AIで作る速さが上がったぶん、何を作り、どう届けるかが一層問われる、という議論が続いています。
