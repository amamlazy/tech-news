Cursor（AIを組み込んだコードエディター）には、機能を追加する「拡張機能」を配る専用のストア（マーケットプレイス）があります。そこで配られていた、AnthropicのAIコーディング機能「Claude Code」の拡張機能に、不正なコードが混ぜ込まれていたことが分かりました。

## 何が起きたのか

窓の杜によると、改ざんされていたのはWindows版とmacOS版の「Claude Code for VS Code」v2.1.312とv2.1.313です。日本時間の10月29日18時27分から30日5時35分までマーケットプレイスに置かれており、最大5,000人が影響を受けた可能性があります。

## 不正なコードがしたこと

- 攻撃者のSSH鍵（SSHはサーバーなどに遠隔ログインする仕組みで、鍵はその合言葉にあたるもの）を、「svc-telemetry」というラベル付きで authorized_keys（ログインを許す鍵の一覧）に追加
- PCの内側から攻撃者側へ「逆向きのSSHトンネル」を張り、外から入り込める通り道を作る
- macOSのLaunchAgentやWindowsのタスクスケジューラーで、再起動後も動き続けるように設定
- 約60秒ごとに接続を試み、PCの情報を集める

コードの分析はセキュリティ企業のPhorionが行いました。AnthropicのFelix Rieseberg氏は、Anthropic側のシステムが侵害されたわけではないと説明しています。

## 利用者がすべきこと

Cursorはマーケットプレイスを止め、署名などに使う鍵を入れ替えました。該当バージョンを入れた人には、v2.1.314への更新を案内しています。ただし、拡張機能をアンインストールしても、常駐の仕組み（鍵の登録や自動起動の設定）は残る可能性があるため、別途の確認が必要です。

## 読みどころ

AIツールは手元のファイルやコマンドに広くアクセスできるため、その配布経路が狙われると被害が大きくなります。自分のPCを実際に点検した手順は、今日の【実践レポート】（Qiitaの確認記事）も参考になります。
