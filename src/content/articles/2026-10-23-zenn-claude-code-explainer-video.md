この記事は、生成AIの導入支援を行う会社エクスプラザのエンジニア、musoukun氏がZennに書いた実践レポートです。Claude Code（Anthropicが作った、ターミナルで動くAIコーディングツール）に、アプリの仕組みを説明する短い動画を作らせる方法を、指示の書き方から動画の作り方まで紹介しています。

## 何を作っているか

筆者は、お客さんにアプリの仕組みを説明するとき、構成図や文章の代わりに「アプリの操作」と「その裏で起きている処理」を交互に見せる解説動画を使っているそうです。記事では、架空の「みどり町図書館の本探しチャット」をダミーで作り、44秒の動画を作り直して見せています。

## 手順

1. 筆者が公開しているスキル（Claude Codeに作業手順を教えるフォルダー）「animated-arch-diagram」を、`~/.claude/skills/` にコピーします。
2. 説明したいアプリのフォルダーで、指示テンプレートにアプリ名などを書き込んでClaude Codeに渡します。
3. アプリの記録（送った質問、途中の結果、返事）をJSONにしたものを用意し、動画に出す数字はすべてここから取らせます。

指示テンプレートの主な中身は次の通りです。

- 形式は「操作 → 仕組み → 操作 → 仕組み」の交互
- 操作の場面は本物そっくりの見本画面（モック）でよく、カーソルが動いてクリックし、クリックや入力に合わせてズームする（画面録画アプリ「Screen Studio」風）
- 仕組みの場面では、送った文字を画面いっぱいに広げ、処理の様子を動きで見せる（文が区切られる、順位の棒が伸びて並べ替わる、など）
- 全体の構成図は、操作の合間に関係する部分だけ差し込む
- 下に小見出しと1行の字幕を付ける

## 動画の作り方

動画は画面を録画しているのではありません。「時刻を渡すと、その瞬間の絵を描くWebページ」を作り、Playwright（ブラウザーを自動で動かす道具）で1/30秒ずつ時刻を進めながら撮影し、ffmpeg（動画を作る道具）に渡してつなげています。

```js
// 1/30 秒ずつ時刻を進めて、そのたびに描かせて撮る
for (let i = 0; i < frames; i++) {
  await page.evaluate((t) => ARCH.render(t), i / 30);
  ffmpeg.stdin.write(await page.screenshot({ type: 'jpeg' }));
}
```

44秒の動画は1,314コマで、書き出しは筆者のMacで約45秒だったそうです。場面ごとに「何秒目に何をするか」を、カーソル移動（cursor）、ズーム（zoom）、文字入力（type）、小見出し（kicker）などの項目で並べて書きます。

## 使ってみてのポイント

- 何度書き出しても同じ動画になるので、直しやすい
- 字幕の数字もアプリの記録から取っているため、アプリを直して流し直せば数字も一緒に変わる

筆者は「Claudeでこういうのがポンと出せるようになって、動画制作がしやすくなっている」と感想を述べています。
