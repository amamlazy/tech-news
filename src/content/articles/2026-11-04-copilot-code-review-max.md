GitHub Copilotは、GitHubが提供するAIのプログラミング支援サービスです。その中の「Copilot Code Review」は、書かれたコードをAIが読んでバグなどを指摘してくれる機能です。ここに、最も念入りに調べる新しいモードが加わりました。

## 何が変わったのか

Publickeyによると、GitHub Universe 2026で「Copilot Code Review Max」が発表されました。これまでのレビューには「Lite」と「Balanced」という2段階の「エフォートレベル（どれだけ手間をかけて調べるかの強さ）」があり、新しく「Max」が加わった形です。

AIエージェントが作るプルリクエスト（コードの変更を取り込んでほしいという申請）が急増していて、品質を保つためにレビューの重要性が高まっていることが背景にあります。

## 仕組み

- 複数のAIモデルを使った、複数の独立したレビューエージェントが同時に動く
- モデルごとの長所と盲点を組み合わせ、1つのモデルでは見落としがちな問題を見つける
- まとめ役の「集約エージェント」が、意見の食い違いを整理して正しさを再確認してから報告する

GitHubによると、評価用のテスト「ReviewBench」で、重大度の高い問題を見つける性能を表す「F1スコア（見逃しの少なさと誤報の少なさを合わせた指標）」が最も高かったとしています。

## 読みどころ

「AIが書いたコードを、別のAIたちがレビューする」流れが本格化しています。現在はパブリックプレビュー（誰でも試せる試用版）なので、重要な変更のレビューで人間の確認と併用してみるのが現実的です。
