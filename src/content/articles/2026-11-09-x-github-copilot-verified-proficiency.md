GitHub Copilotは、コードの補完や作業の代行をしてくれるGitHubのAIアシスタントです。そのCopilotを「どれだけ使いこなせているか」を、テストではなく日々の利用実績から示す仕組みをGitHubが打ち出しました。

## 投稿の内容

GitHub公式アカウントは11月6日（日本時間）、「Copilotのスキルを評価する新しい方法」として「GitHub Copilot Verified Proficiency」を投稿しました。Copilotを使って仕事をする中で示した能力を継続的に測るもので、「試験はなく、データだけ」と説明し、熟練度レベルの算出方法を解説するページ（learn.github.com）へ案内しています。

## キャリアの観点で見るところ

AIコーディングツールの使いこなしが、エンジニアの評価軸の一つになりつつあります。資格試験のような一時点の測定ではなく、実際の作業データから継続的に示すというアプローチは、採用や社内評価での使われ方に影響する可能性があります。一方で、どのデータをどう評価するのか、利用量の多さが過大に評価されないかなどは、算出方法の詳細を確認しておきたいところです。投稿への反応は約300件のいいね、50件のリプライでした。
