Windowsは、正規品かどうかを確認する「ライセンス認証」を行っています。企業では、社内のサーバーでまとめて認証するKMS（キー管理サービス）や、そのためのコマンド「slmgr.vbs」を使って、多数のPCの認証を管理していることがあります。今回の問題は、この企業向けの管理作業に関わるものです。

## 何が起きていたか

窓の杜によると、2026年11月のセキュリティ更新プログラムを入れた一部の企業向けデバイスで、ソフトウェアライセンス管理ツール（SLMGR）を使ったライセンス認証の操作が、エラー「0x80041008」（Invalid parameter）で失敗することがありました。

主に影響を受けるのは、slmgr.vbsのコマンドや自動化された処理で、次のような作業をしている組織です。

- KMSによるライセンス認証の構成
- プロダクトキーのインストール
- ライセンスの管理

すでに認証済みの端末は認証済みのまま変わらず、追加のslmgr.vbsコマンドを使わない既存のKMS構成の端末も影響を受けないとしています。

## 更新プログラムの一覧

今回の更新は累積更新で、11月のセキュリティ更新などの過去の内容も含んでいます。

- Windows Server 2025：KB5136489
- Windows Server 2022：KB5136487
- Windows Server 2019／Windows 10 Enterprise LTSC 2019：KB5136490
- Windows 11 バージョン 23H2：KB5136483
- Windows 10 バージョン 22H2（ESU）／Windows 10 Enterprise LTSC 2021：KB5136493

いずれもセキュリティ以外の「オプション」の更新で、問題が起きていなければ入れる必要はありません。Windows ServerとWindows 10向けは「Microsoft Update カタログ」からのみ入手できます。Windows 11 23H2向けは、Windows Updateの［オプションの更新プログラム］からも入れられます。

## 現場で見るところ

PCの初期設定やキーの入れ替えをスクリプトで自動化している情シス部門は、11月の更新を入れたあとにエラーが出ていないか確認しておくとよさそうです。なお窓の杜は関連記事で、VBScriptの廃止に備えて、認証の自動化をslmgr.vbsからPowerShellに移すことも紹介しています。
