## 何が話題か

雪代氏（@yksr_melt）が、半角/全角キーを押さなくても日本語と英語を混ぜて打てる日本語入力「Meltype」を作ったと X に投稿した。例として「kyouhagithubnipushshita」と打つと「今日はgithubにpushした」になる様子を紹介しており、投稿には2,500件以上のいいねと2,600件以上のブックマークが付いている。

## どんなツールか

GitHub の README によると、Meltype は Windows に常駐するツールで、Windows 標準の Microsoft IME と組み合わせて使う。日本語の部分は変換ボックスでかな漢字に変換し、「google」「github」のような英単語や英文は英字のまま残す。VS Code やターミナルでは基本は英数入力にして、コメントや文字列の中だけ日本語にする。絵文字の変換やよくある書き間違いの指摘もある。

判定と変換はすべて PC の中で行い、打った内容をネットワークに送らないと明記している。Mac 版と Linux 版（IBus エンジン）はプレビュー版で、一部機能はまだない。

## 現場で見るところ

コードとコメント、チャットで日英を行き来するエンジニアには刺さる題材だ。キーボード入力を扱うソフトなので、README にあるとおりコード署名がない点や、配布 zip の SHA-256 を確かめる手順を踏んでから試したい。
