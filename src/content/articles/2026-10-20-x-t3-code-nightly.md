T3 Codeは、YouTuberで開発者のTheo（Theo Browne）氏らのチームが作っている、AIコーディングツールを操作するためのアプリです。Claude CodeやCodex、Cursor、OpenCode、Grok Build、Antigravityといったツールを、1つの画面からまとめて動かせます。

## どんなアプリか

GitHubのREADMEによると、T3 Codeは自らを「エージェントハーネスのコントロールサーフェス」と呼んでいます。エージェントハーネスはAIに作業をさせるための土台となるツールのことで、それらを外から操る操作盤という意味です。デスクトップアプリ、Webアプリ、スマホアプリがあり、自分のPCで動いているエージェントを外出先からも操作できます。

利用料はかからず、ユーザーがすでに契約しているClaude CodeやCodexのプランをそのまま使います。作業ごとにGitのブランチを分けて進め、ボタン1つでコミットからPR作成までできるのも特徴です。ライセンスはMITで、プロジェクトは「まだ非常に初期の段階」とされています。

## Xの反応

Theo氏（@theo）は10月19日、デモでクリックしていたT3 Codeのスレッドはすべて、VPS（ネット上に借りるサーバー）や家のLinuxマシンなど別のマシンで動いていたと投稿しました。比較に出したCodexのほうはほとんどがローカルで動いていたとして、「まだT3 Codeに移っていないなら、なぜ？」と呼びかけています。この投稿は約7万6,000回表示されました。

その1時間ほど前にも、Theo氏は最新の試験版（nightly）の速さについて「データがハードコードされているのでは、と思うほど」と投稿し、約12万回表示されています。

- @mohtasham は、T3 Codeは市場で圧倒的に速いと投稿した
- @ryoppippi は「t3 code is good」と投稿した
- @imtyl3r_ は、最も完成度の高いエージェント操作アプリだと投稿した
- @inprealpha は、1つのボタンに複数の機能があるなど、UIに使いにくい部分もあると投稿した

Theo氏は、直近2週間にCodexを使ったT3 Code利用者の6割以上がClaude Codeも使っていたとも投稿しました。これに対して、@justmaocom などは、あくまでT3 Codeを使っている人たちの中での数字だと注意を促しています。

## 試すなら

複数のAIコーディングツールを使い分けている人ほど、画面を行き来する手間が減ります。ただし公式も「バグはある前提で」としているので、まずは`npx t3@latest`で試しに動かしてみるのが手軽です。
